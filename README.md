## 0.管理插件

PluginManage，如果你想添加自己的插件，可以阅读它的init文件，我把规则写在最上面了，如果你想在群聊中管理插件：

MGstate：查看当前所有插件的状态，提供插件名可以查看它的详细状态

MGtoggle：提供插件名后可以控制该功能的整体开关

MG添加黑/白名单：提供插件名和群号后可以单独控制该群开关，记得先在配置文件里调整黑白名单模式
